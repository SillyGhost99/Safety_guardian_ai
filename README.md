# Safety_guardian_ai

AI Tourist Guardian: SafeTravel AI
Concept
An AI-powered tourist safety companion for visitors, solo travelers, women travelers, and pilgrims
across the MENA region. Instead of waiting for the user to ask for help, the AI continuously
evaluates risk using telecom network intelligence (CAMARA APIs) and phone context, then
proactively assists when needed.
Problem
Tourists often face unfamiliar surroundings, language barriers, scams, getting lost, and delayed
emergency response.
Target Users
Solo women travelers, families, pilgrims, business travelers, students, and tourists.
Core Features
• Guardian Mode during trips.
• Live safe-route monitoring.
• Geofence alerts when entering risky or restricted areas.
• AI risk score using location, device status, connectivity and optional phone sensors.
• Wellness check if unusual behavior is detected.
• Emergency SOS with live location sharing.
• QoS on Demand for reliable emergency calls.
• Family tracking (opt-in).
• Nearby embassy, police, hospital and safe spaces.
• AI multilingual translator for emergency phrases.
CAMARA APIs
Location Retrieval, Geofencing, Device Status, QoS on Demand, Number Verification, Device
Reachability (if available).
AI Agent Workflow
1. User starts Guardian Mode.
2. AI monitors route and telecom signals.
3. Calculates dynamic risk score.
4. Low risk: no action.
5. Medium risk: asks 'Are you okay?'
6. High risk/no response: shares live location, alerts contacts, requests QoS, provides nearest safe
destination.
UI/UX
Home: large 'Start Guardian Mode' button, trip cards.
Map: live route, safe zones (green), caution (yellow), restricted (red).
Emergency Screen: one-tap SOS, silent SOS, emergency contacts.
AI Chat: travel assistant, safety tips, translation.
Profile: contacts, language, privacy controls.
